# Targets.Sdk

[![NuGet](https://img.shields.io/nuget/v/Targets.Sdk?style=for-the-badge)](https://www.nuget.org/packages/Targets.Sdk) [![License](https://img.shields.io/github/license/robertcoltheart/targets-sdk?style=for-the-badge)](https://github.com/robertcoltheart/targets-sdk/blob/master/LICENSE)

A simple target-driven framework for builds.

## Usage
Install the package from NuGet with `dotnet add package Targets.Sdk`.
